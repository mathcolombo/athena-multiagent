# Regras de negócio

| ID | Regra |
|---|---|
| RN-01 | Todo preço é não negativo e expresso em centavos. |
| RN-02 | Alterações de preço devem chegar ao carrinho, que sempre usa o preço vigente até o checkout. |
| RN-03 | A reserva de estoque é tudo ou nada para os itens do pedido. |
| RN-04 | Um pedido só é confirmado depois da reserva de estoque. |
| RN-05 | Cada checkout gera exatamente um pedido. |
| RN-06 | Carrinho finalizado não aceita alterações. |
